# 图片预算守卫

DSH 的会话日志只追加，每个模型请求都会重发完整历史。图片在 token 上便宜、在字节上很贵：一张 1920×1080 截图最多约 1024 个视觉 token，却对应约 0.7 MB 请求体。长会话里请求体会先涨到十几 MB，而按 token 触发的压缩还没到阈值。

本插件在请求组装**之前**把最旧的图片替换为占位文本，直到请求回到预算内：

- **主动裁剪**：不再等适配器报错重试，本次请求发出时就已经变小。
- **双重预算**：内联路由同时限制字节数与图片张数；Files 路由只限制张数。
- **保留下限**：最新若干张、以及最近若干步内出现的图片永不省略。
- **可回放**：决策写入会话日志的 `image/offload` 事件，重启、恢复、分叉后行为一致。

## 两个开关值得先看

- **`mistralImageLimit`（Mistral 专用）**：Mistral 会拒绝第 21 张图，即使请求体只有几 MiB。打开后，provider 名为 `mistral` 的路由图片上限固定为 20 张，其他供应商不受影响。
- **`dryRun`**：只记录将省略哪些图片，不写事件、不改请求。建议先用它观察一个图片密集的会话。

省略是不可逆的：被省略的图片在本会话余下部分一直是占位符。完整配置与调优见仓库 README。
